<objective>
Replace Express's silent env fallbacks (`env.ts`, insecure `JWT_SECRET` fallback) with a fail-fast, Joi-validated ConfigModule.
</objective>

<concepts>
- Dynamic modules (`ConfigModule.forRoot`), `isGlobal`
- Joi schema, `abortEarly`, defaults vs required
- `ConfigService.get<T>()` and injecting it (first real use of DI with a framework provider)
- Fail-fast principle (Day 1)
</concepts>

<steps>
1. `npm i @nestjs/config joi`.
2. Create `src/config/env.validation.ts` (NODE_ENV, PORT default 5001, DATABASE_URL required, JWT_SECRET min 32 required, JWT_EXPIRES_IN default 7d).
3. Register `ConfigModule.forRoot` in `AppModule`.
4. In `main.ts`, get `ConfigService` via `app.get()` and listen on `PORT`.
5. Break it on purpose: remove JWT_SECRET, then shorten it, then restore.
</steps>

<verify>
- Missing/short JWT_SECRET: process exits before listening, with a Joi message.
- Valid `.env`: app serves on 5001.
- `grep -rn "process.env" backend-nest/src` returns only `main.ts`/config code if anything.
